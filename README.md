Transcrify è un’app Android personale che sperimenta l’uso di speech-to-text e modelli LLM per trasformare note vocali in testo più leggibile e strutturato.

L’app nasce dall’esigenza personale di convertire rapidamente messaggi vocali in testo, migliorandone la chiarezza tramite rielaborazione automatica.
Il sistema è basato su un Android Accessibility Service con overlay fluttuante, che permette di avviare la registrazione in qualsiasi contesto e ottenere la trascrizione copiata direttamente negli appunti.

Funzionalità principali
- Trascrizione vocale tramite API speech-to-text (Whisper v3 Large di OpenAI)
- Rielaborazione opzionale del testo tramite LLM
- Overlay fluttuante per accesso rapido alle funzioni di registrazione
-Copia automatica del testo negli appunti di sistema

### Evoluzione del progetto
Il progetto ha attraversato diversi prototipi sperimentali di interfaccia e interazione, con l’obiettivo di semplificare il flusso d’uso e migliorare l’accessibilità dell’esperienza.

### Nota sul progetto
- Il progetto è nato come esplorazione personale su speech-to-text, interazione mobile, overlay Android e integrazione di API AI.
- Il progetto si è focalizzato su interazione vocale, UX non invasiva e accesso rapido alle funzioni tramite overlay.
